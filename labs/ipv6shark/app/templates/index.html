Configuring Local IPv6 Domain Resolution

To access IPv6 Shark using the custom domain http://ipv6.lab:8090, configure your system's local hosts file with both IPv4 and IPv6 loopback entries.

Linux / macOS Configuration

Run the following command in your terminal to append the IPv6 mapping to /etc/hosts:

echo "::1 ipv6.lab" | sudo tee -a /etc/hosts
echo "127.0.0.1 ipv6.lab" | sudo tee -a /etc/hosts
Windows PowerShell Configuration

Run PowerShell as Administrator and execute:

Add-Content -Path C:\Windows\System32\drivers\etc\hosts -Value "::1 ipv6.lab"
Add-Content -Path C:\Windows\System32\drivers\etc\hosts -Value "127.0.0.1 ipv6.lab"
